AI Trading Bot: Companion

Watch and control your trading bot from the toolbar.

Server

The AI Trading Bot desktop app runs its server on this computer at http://127.0.0.1:47821. If that port is busy it uses the next free one (up to 47841): the app's tray menu shows the exact server URL, or press Find the desktop app. For a self-hosted server (for example the Docker deployment), enter its https:// address; Chrome then asks you to allow access to that site.

Account

Signed in to as

Use the account you created in the desktop app (its first account is the administrator). Bot status, alerts and controls need an administrator; any account can analyse tickers. Your password is sent only to the server above and is never stored: the extension keeps a refresh token in its local storage and a short-lived access token in memory. Signing out removes both.

Alerts need an administrator account. The badge on the toolbar icon shows the bot state: RUN running, OFF paused, HALT halted, FLAT flatten pending, LATE no recent cycle, DATA data fault, ERR failing cycles, DOWN server unreachable, ? not signed in.

Privacy

The extension never reads the content of the pages you visit and has no content scripts. When you open its popup, it looks at the address of the current tab (and only that tab, only then) to recognise a ticker on Yahoo Finance, Google Finance, TradingView, MarketWatch, Seeking Alpha, Finviz, CNBC, Nasdaq.com, NSE or BSE. It talks only to the server configured above; nothing is sent anywhere else.
